# Valheim Host Pranks

Небольшой мод для хоста сервера в Valheim для эпичных кинематографичных пранков над друзьями.

## Что умеет:
* **⚡ Кинематографичное явление Одина:**
  1. **Тревожная стая в небе (13 секунд):** На широком радиусе 25–45 метров вокруг викинга в небесах начинает долго и хаотично кружить стая из 30 черных воронов с периодическим карканьем.
  2. **Схождение вихрем (2.4 сек):** Стая синхронно и плавно пикирует в одну точку на земле в 10 метрах перед игроком.
  3. **Рождение из тьмы:** При ударе птиц о землю происходит взрыв темного дыма — из него появляется величественный Один с посохом.
  4. **Пауза и зарядка посоха (2.8с + 1.6с):** Один выдерживает зловещий зрительный контакт, затем медленно поднимает посох к небу со звуком нарастающего электрического треска и сиянием синей плазмы.
  5. **Удар 3D-молнии со звуком:** С неба бьет ветвистая 3D-молния с резким звуком электрического разряда и глубоким громовым раскатом. Игрока обдает взрывной волной и отбрасывает на 2 шага назад (**0 урона, 100% безопасность**).
  6. **Исчезновение и веерный разлет воронов:** Сам Один в этот же миг растворяется в клубах черного дыма, а из точки его исчезновения во все стороны света (веером на 360°) с криками разлетаются 24 черных ворона, плавно скрываясь за горизонтом.
* **🧹 Очистка лишних ворон:** В меню добавлена кнопка быстрой очистки застрявших ворон возле базы в радиусе 120 метров.

Меню работает **только у хоста** (на чужих серверах открыть нельзя).

## Управление
* Нажмите **F8**, чтобы открыть меню со списком игроков.
* Клавишу можно изменить в конфиге `BepInEx/config/com.anonim.valheimhostpranks.cfg`.

## Установка
1. Установите **BepInExPack Valheim**.
2. Скопируйте файл `ValheimHostPranks.dll` в папку `Valheim/BepInEx/plugins/ValheimHostPranks/`.
3. Перезапустите игру.
