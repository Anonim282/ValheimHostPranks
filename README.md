# Valheim Host Pranks

Небольшой мод для хоста сервера в Valheim, позволяющий безобидно пранковать друзей.

## Что умеет:
* **🦟 Комар в ухо** — создает 3D-звук кружащегося комара равнин прямо вокруг головы выбранного игрока. Игрок слышит панический писк и вертит головой в поисках опасности.
* **⚡ Кара Одина** — прямо перед игроком из тумана материализуется силуэт Одина с посохом. Через пару секунд раздается гром и бьет молния со вспышкой и тряской камеры, после чего старик свечой улетает в небо и исчезает.

Меню работает **только у хоста** (на чужих серверах открыть нельзя).

## Управление
* Нажмите **F8**, чтобы открыть/закрыть меню пранков со списком игроков.
* Клавишу можно изменить в конфиге `BepInEx/config/com.anonim.valheimhostpranks.cfg`.

## Установка
1. Установите **BepInExPack Valheim**.
2. Скопируйте файл `ValheimHostPranks.dll` в папку `Valheim/BepInEx/plugins/`.
3. Запустите игру и создайте мир (или сервер).
