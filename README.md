# Valheim Host Pranks

Небольшой мод для хоста сервера в Valheim для эпичных кинематографичных пранков над друзьями.

## Что умеет:
* **⚡ Кинематографичное явление Одина:**
  1. **Стая черных воронов:** В радиусе 20 метров вокруг игрока в воздухе с карканьем начинает тревожно кружить стая черных птиц.
  2. **Схождение лавиной:** Через 2.5 секунды вся стая синхронно пикирует в одну точку на земле в 10 метрах перед игроком.
  3. **Рождение из тьмы:** При ударе птиц о землю происходит взрыв темного дыма и перьев — из него материализуется величественный Один с посохом.
  4. **Взмах посохом:** Набалдашник посоха Одина начинает искриться синей плазмой, старик вскидывает его и с силой ударяет оземь.
  5. **Удар 3D-молнии и ударная волна:** С неба бьет ветвистый зигзаг молнии, раздается оглушительный гром, а игрока обдает взрывной волной и отбрасывает на 2 шага назад (**0 урона, 100% безопасность**).
  6. **Взлет с Хугином и Мунином:** Один свечой взмывает в небо, а по бокам от него ввысь устремляются два верных ворона, растворяясь в облаках.

Меню работает **только у хоста** (на чужих серверах открыть нельзя).

## Управление
* Нажмите **F8**, чтобы открыть меню со списком игроков.
* Клавишу можно изменить в конфиге `BepInEx/config/com.anonim.valheimhostpranks.cfg`.

## Установка
1. Установите **BepInExPack Valheim**.
2. Скопируйте файл `ValheimHostPranks.dll` в папку `Valheim/BepInEx/plugins/ValheimHostPranks/`.
3. Перезапустите игру.
