# Valheim Host Pranks

Небольшой мод для хоста сервера в Valheim для эффектных и безопасных пранков над друзьями.

## Что умеет:
* **⚡ Кара Одина** — в 10 метрах перед игроком материализуется величественный силуэт Одина с посохом. Старик выдерживает зловещую паузу, после чего с небес (высота 60 метров) с оглушительным раскатом грома прямо в землю перед игроком бьет ветвистая 3D-молния со снопом искр и сильной тряской экрана. Сразу после удара Один свечой взмывает в небо и растворяется в облаках.
  * **0 урона:** Пранк полностью визуальный и кинематографичный — игрок не теряет здоровье и навыки.

Меню работает **только у хоста** (на чужих серверах открыть нельзя).

## Управление
* Нажмите **F8**, чтобы открыть меню со списком игроков.
* Клавишу можно изменить в конфиге `BepInEx/config/com.anonim.valheimhostpranks.cfg`.

## Установка
1. Установите **BepInExPack Valheim**.
2. Скопируйте файл `ValheimHostPranks.dll` в папку `Valheim/BepInEx/plugins/ValheimHostPranks/`.
3. Запустите игру.
