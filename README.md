# Valheim Host Pranks

Небольшой мод для хоста сервера в Valheim для безобидных и атмосферных пранков над друзьями.

## Что умеет:
* **⚡ Кара Одина** — в 10 метрах перед игроком из темного тумана материализуется величественный силуэт Одина с посохом. Старик выдерживает зловещую паузу, после чего землю озаряет ослепительная вспышка молнии с оглушительным громом и тряской экрана викинга. Сразу после удара Один свечой взмывает в небо и растворяется в облаках.
  * **0 урона:** Пранк полностью безопасен, игрок не теряет здоровье и навыки.

Меню работает **только у хоста** (на чужих серверах открыть нельзя).

## Управление
* Нажмите **F8**, чтобы открыть меню со списком игроков.
* Клавишу можно изменить в конфиге `BepInEx/config/com.anonim.valheimhostpranks.cfg`.

## Установка
1. Установите **BepInExPack Valheim**.
2. Скопируйте файл `ValheimHostPranks.dll` в папку `Valheim/BepInEx/plugins/ValheimHostPranks/`.
3. Запустите игру.
